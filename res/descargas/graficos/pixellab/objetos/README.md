# Pixellab → objetos, efectos y armas de la fase 1

Deja aquí las piezas pequeñas (git ignora todo lo que pongas aquí salvo este
README). Lista, tamaños y prompts:
[`docs/pixellab-fase1.md`](../../../../../docs/pixellab-fase1.md) §5.

Van **en una sola sesión de Pixellab** porque comparten la **paleta 7** (15
colores); las chispas y la nube de relevo, la paleta 5, y el polvo, la 4. Son
translúcidos en combate: colores claros.

## Piezas

- 32×32, intacto + 3 de rotura: `barril`, `caja`, `jarra`.
- 32×64, intacto + 3 de rotura: `farol` (aldea), `shoji` (dojo).
- 16×16: `shuriken` (2 en vuelo + 1 en el suelo), `kunai` (1 + 1), `onigiri`,
  `pescado`, `vida_extra` (2, brilla), `chispa` (3), `polvo` (4), `hojas` /
  `petalos` / `luciernagas` (2–3).
- 32×32: `golpe_fuerte` (4), `nube_relevo` (5).

**No van aquí:** el Señor Pimentón (lo aportas tú, en `res/descargas/graficos/`),
las sombras y el «GO →» (a mano).
